# BSMappingData

Features
```
v2                                                  - V2 map and V2 info parsing
v3                                                  - V3 map and V2 info parsing
v4                                                  - V4 map and V4 info parsing
custom_data                                         - Custom data support
settings_setter : custom_data                       - Adds dedicated Settings Setter data fields
tracks          : custom_data                       - Adds dedicated tracks data fields
chroma          : custom_data, tracks               - Adds dedicated chroma data fields
noodle          : custom_data, tracks               - Adds dedicated noodle data fields
beatcraft       : custom_data                       - Adds dedicated beatcraft data fields
heck            : noodle, chroma, settings_setter   - 
all-versions    : v2, v3, v4                        - 
default         : heck, beatcraft, all-versions     - 
```
